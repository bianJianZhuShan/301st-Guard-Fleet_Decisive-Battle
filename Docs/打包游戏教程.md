## 打包前准备

### 1. 确保项目可以正常运行

在打包之前，请确保：

- 项目在编辑器中可以正常运行（PIE模式）
- 没有编译错误
- 游戏的主要功能都能正常工作

### 2. 设置默认地图

1. 打开 **编辑 (Edit)** → **项目设置 (Project Settings)**
2. 在左侧找到 **项目 (Project)** → **地图和模式 (Maps & Modes)**
3. 设置以下选项：
   - **编辑器启动地图 (Editor Startup Map)**: 选择你的主地图
   - **游戏默认地图 (Game Default Map)**: 选择你的主地图（打包后启动的地图）

### 3. 检查打包设置

1. 打开 **编辑 (Edit)** → **项目设置 (Project Settings)**
2. 在左侧找到 **项目 (Project)** → **打包 (Packaging)**
3. 确认以下设置：
   - **构建配置 (Build Configuration)**: 
     - `Development`: 用于测试，包含调试信息
     - `Shipping`: 用于最终发布，性能最优
   - **完整重建 (Full Rebuild)**: 首次打包建议勾选

## 打包步骤

### 方法一：通过菜单打包（推荐）

1. 在编辑器顶部菜单栏，点击 **平台 (Platforms)**
2. 选择 **Windows** → **打包项目 (Package Project)**
3. 选择一个输出文件夹（建议选择项目外的空文件夹）
4. 等待打包完成（首次打包可能需要 10-30 分钟）

### 方法二：通过快捷方式

1. 点击工具栏上的 **平台 (Platforms)** 下拉按钮
2. 选择目标平台（Windows）
3. 点击 **打包项目 (Package Project)**

### 打包过程

打包过程中会显示进度：

1. **编译着色器**: 编译所有材质的着色器
2. **烘焙内容**: 处理和优化游戏资源
3. **构建**: 编译游戏代码
4. **打包**: 将所有内容打包成可执行文件

> ⚠️ **注意**: 首次打包时间较长，请耐心等待。后续打包会更快。

## 打包设置详解

### 项目设置 → 打包

| 设置项 | 说明 | 推荐值 |
|--------|------|--------|
| **构建配置** | Development（测试）/ Shipping（发布） | Development |
| **完整重建** | 是否完全重新构建 | 首次勾选 |
| **使用Pak文件** | 将资源打包成.pak文件 | ✓ 勾选 |
| **生成块** | 分块打包，便于DLC | 不勾选 |
| **包含调试文件** | 包含调试符号 | 测试时勾选 |

### 要包含的地图

如果只想打包特定地图：

1. 在打包设置中找到 **要包含的地图列表 (List of maps to include)**
2. 添加你需要的地图

### 排除不需要的内容

1. 找到 **要排除的目录 (Directories to never cook)**
2. 添加不需要打包的文件夹路径

## 常见问题解决

### 问题1：打包失败 - 着色器编译错误

**解决方案**：
1. 打开 **窗口 (Window)** → **着色器编译 (Shader Compilation)**
2. 等待所有着色器编译完成
3. 重新打包

### 问题2：打包失败 - 缺少资源

**解决方案**：
1. 检查输出日志中的错误信息
2. 确保所有引用的资源都存在
3. 使用 **资源审计 (Asset Audit)** 检查资源引用

### 问题3：打包后游戏无法启动

**解决方案**：
1. 检查是否安装了必要的运行时：
   - Visual C++ Redistributable
   - DirectX
2. 以管理员身份运行游戏
3. 检查防火墙设置

### 问题4：打包后画面异常

**解决方案**：
1. 确保在打包前保存了所有地图
2. 检查光照是否已构建
3. 重新构建光照后再打包

### 问题5：打包文件过大

**解决方案**：
1. 删除不需要的资源
2. 压缩纹理（在纹理设置中调整压缩级别）
3. 使用 **Size Map** 工具分析资源大小

## 发送给朋友

### 打包完成后的文件结构

```
输出文件夹/
├── Windows/
│   ├── newProject/
│   │   ├── Binaries/
│   │   ├── Content/
│   │   └── ...
│   └── newProject.exe    ← 游戏启动程序
```

### 发送方式

#### 方式1：压缩后发送

1. 将整个 `Windows` 文件夹压缩成 `.zip` 或 `.7z` 文件
2. 通过网盘（百度网盘、阿里云盘等）分享给朋友
3. 朋友下载后解压，运行 `newProject.exe`

#### 方式2：使用文件传输工具

- **蓝奏云**: 适合小文件（100MB以下）
- **百度网盘**: 适合大文件
- **阿里云盘**: 不限速
- **123云盘**: 免费大容量

### 朋友需要安装的运行时

请告诉朋友安装以下运行时（如果游戏无法启动）：

1. **Visual C++ Redistributable 2015-2022**
   - 下载地址: https://aka.ms/vs/17/release/vc_redist.x64.exe

2. **DirectX End-User Runtime**
   - 下载地址: https://www.microsoft.com/en-us/download/details.aspx?id=35

### 发送清单模板

发送给朋友时，可以附上以下说明：

```
游戏测试版本 v0.1

安装说明：
1. 解压压缩包到任意位置
2. 运行 newProject.exe 启动游戏
3. 如果无法启动，请安装 Visual C++ 运行时

操作说明：
- 鼠标左键：选择单位/确认操作
- 鼠标右键：取消选择
- 滚轮：缩放视角
- WASD：移动视角
- 空格：结束回合

已知问题：
- [列出已知的bug]

反馈方式：
- 请将问题截图发送给我
```

## 附录：命令行打包

如果需要自动化打包，可以使用命令行：

```powershell
# 打包 Windows 版本
"D:\ue\UE_5.7\Engine\Build\BatchFiles\RunUAT.bat" BuildCookRun ^
    -project="D:\ue\project\newProject\newProject.uproject" ^
    -platform=Win64 ^
    -clientconfig=Development ^
    -cook -stage -package -archive ^
    -archivedirectory="D:\Output"
```
