## 技术要点

- 视线检测：使用 `LineTraceSingleByChannel`
- 平滑视角切换：使用 `SetViewTargetWithBlend`
- AI决策：使用行为树或简单状态机
- 移动动画：使用 `FInterpTo` 或 Timeline
