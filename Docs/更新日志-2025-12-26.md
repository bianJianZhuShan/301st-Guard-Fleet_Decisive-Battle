# 2025年12月31日 (v0.0.2.0)

## 1. 反击窗口系统

### 新增功能
- **反击窗口机制**：当敌方单位移动进入我方舰船攻击范围时，触发反击窗口
- **10秒决策时间**：反击方有10秒时间决定是否进行反击
- **暂停对方操作**：反击窗口期间，被反击方无法操作
- **反击限制**：只有拥有反击点的一方才会触发反击窗口
- **反击操作**：反击窗口期间可进行攻击、旋转等操作（不能移动）

### 修改文件
- `TacticalGameState.h/cpp`：添加反击窗口系统（`bIsInCounterWindow`, `CounterWindowTimeout`, `StartCounterWindow()`, `EndCounterWindow()`, `TickCounterWindow()`）
- `TacticalGameMode.h/cpp`：AI移动后检查玩家反击触发，添加 `ResumeAIAfterCounterWindow()`
- `TacticalPlayerController.cpp`：Tick中检查反击窗口状态，暂停非反击方操作

## 5. 创建半透明材质（需手动操作）

在UE编辑器中创建 `/Game/Materials/M_RangeSphere`：

1. Content Browser → 右键 → Material → 命名 `M_RangeSphere`
2. Details 面板设置：
   - **Blend Mode**: Translucent
   - **Shading Model**: Unlit
   - **Two Sided**: ✅
3. 创建节点：
   - Vector Parameter `BaseColor`
   - Scalar Parameter `Opacity` (默认0.25)
   - Two Sided Sign + If 节点（只渲染背面）
4. 连接：BaseColor → Emissive Color，If输出 → Opacity
5. Apply & Save

## 2. 房间界面重构

### 主机视图 (玩家A)
- 左侧：显示自己的信息（玩家1/先手）
- 右侧：显示玩家2信息
  - 未连接时：名称=空，状态=未连接
  - 已连接未准备：显示对方名称，状态=未准备
  - 已连接已准备：显示对方名称，状态=已准备
- **开始游戏按钮**：仅当对方**连接且准备**后才能点击

### 客户端视图 (玩家B)
- 左侧：显示主机信息（玩家1/先手）
- 右侧：显示自己信息 + **准备按钮**
- 无法点击"开始游戏"，只能点击"准备"

### 修复问题
- ✅ 创建房间后玩家2不再自动显示为已连接
- ✅ 玩家B加入后不再直接进入游戏，而是进入房间页面

### 根本原因
`TacticalGameState.ConnectedPlayerCount` 默认值为1，导致主机登录时被误认为是第二个玩家。

### 修复方案
- `TacticalGameState.h`: `ConnectedPlayerCount` 默认值改为 **0**
- `TacticalGameMode.cpp`: `PostLogin()` 先递增计数器，再判断是主机还是客户端
- `TacticalPlayerController.cpp`: `CreateRoom()` 移除手动设置计数器
- `TacticalPlayerController.cpp`: `JoinGame()` 不再设置 `bSkipMainMenuOnce`

## 2. AI 对战按钮修复

### 修改内容

#### TacticalPlayerController.cpp - OnAIBattleClicked()
从占位实现改为真正功能：
```cpp
void ATacticalPlayerController::OnAIBattleClicked()
{
    // 关闭主菜单
    if (ATacticalHUD* TacticalHUD = Cast<ATacticalHUD>(GetHUD()))
    {
        TacticalHUD->SetMainMenuVisible(false);
    }

    // 清理联机状态
    if (UTacticalGameInstance* TGI = Cast<UTacticalGameInstance>(GetGameInstance()))
    {
        TGI->bSkipMainMenuOnce = true;
        TGI->bIsHostingRoom = false;
        TGI->bIsClient = false;
        TGI->bOpponentConnected = false;
    }

    // 进入 AI 测试地图
    UGameplayStatics::OpenLevel(this, FName(TEXT("AI-Map01")));
}
```

#### TacticalHUD.cpp
- 按钮文字从 `AI 对战（占位）` 改为 `AI 对战`

## 4. 正确的在线对战流程（修复后）

1. **A 点击"创建房间"** → 启动 Listen Server，留在 Launcher 地图等待
2. **B 输入 IP（如 `10.0.0.2`）点击"加入"** → 连接到 A 的 Launcher
3. **B 加入成功** → A 看到"对方已连接"，开始按钮变为可点击
4. **A 点击"开始游戏"** → 双方一起跳转到 `test-Map02`
5. **进入战斗** → A 控制 x=0 的单位，B 控制 x=9 的单位
