## 今日完成内容

### 1. 单位战斗系统 ✅

#### 1.1 战斗属性
为 `UnitActor` 添加了完整的战斗属性：
- **血量**: 10点 (Health / MaxHealth)
- **攻击范围**: 8格 (AttackRange)
- **攻击伤害**: 5点 (AttackDamage)
- **攻击消耗**: 2 AP (AttackAPCost)

#### 1.2 攻击模式
- 点击"攻击"按钮进入攻击模式
- 攻击范围内顶点显示红色高亮
- 鼠标悬停显示红色路径线和伤害信息 (DMG: 5 | 2 AP)
- 点击目标位置或敌方单位发射投射物

#### 1.3 投射物系统 (ProjectileActor)
- 小立方体形状，红色
- 从发射单位位置生成
- 1秒延迟后水平移动到目标位置
- 命中半径150单位内的敌方单位造成伤害
- 到达目标后自动销毁

#### 1.4 死亡效果
- 血量≤0时触发 `Die()` 方法
- 舰船分裂为两个灰色小立方体残骸
- 释放占用的网格位置
- 死亡单位不可选中、不可移动、不可攻击

### 2. 敌我阵营系统 ✅

#### 2.1 敌方单位
- 添加 `bIsEnemy` 属性标识敌我
- 敌方单位使用深灰色材质
- 友方单位使用蓝灰色材质
- 添加 `SetAsEnemy()` 方法动态设置阵营

#### 2.2 敌方单位限制
- 敌方单位不可选中（点击无反应）
- 敌方单位不可操作（移动/攻击）
- 敌方单位可被友方攻击

# 近期更新（追加）

## 2025年12月18日

### 1. 旋转功能 ✅

- 新增“旋转”按钮：进入/退出旋转模式
- 旋转模式范围提示：以单位为中心，高亮半径=3格的点位
- 悬停预览：显示单位到目标点位的黄色路径线
- 点击规则：
  - 点击空地必须点击到高亮点位才生效
  - 点击敌方单位可直接转向（无需点位高亮）
- 旋转为三维球面旋转：允许俯仰（不再仅水平转向）
- 攻击时自动朝向目标点

### 2. UI 调整 ✅

- 底部UI栏高度调整为屏幕高度的20%
- 同步信息面板与按钮区域布局，避免残留固定高度

### 3. 部署与舰船表现（前两天内容补记）✅

- 敌我部署分界改为X轴：
  - 己方部署：X=0~2（X=2为前排）

- 舰船缩放按类型分级：以“重巡”为基准，每降一级缩小25%
- 敌方舰船默认朝向调整：旋转180度面向己方
