# 快捷键说明

> **20.3 版本更新**：快捷键已重构为 WASD 移动摄像头

## 鼠标操作

| 按键 | 功能 | 说明 |
|------|------|------|
| **左键单击** | 选中/操作 | 点击友方单位选中；在移动/攻击/旋转模式下点击目标执行操作 |
| **左键双击** | 聚焦单位 | 双击友方单位，摄像头聚焦到该单位后方上方 |
| **右键单击** | 取消选择 | 取消当前选中的单位，退出移动/攻击/旋转模式 |
| **滚轮向上** | 摄像头拉近 | 缩小视野距离 |
| **滚轮向下** | 摄像头拉远 | 放大视野距离 |

## 键盘操作

| 按键 | 功能 | 说明 |
|------|------|------|
| **W** | 向前移动摄像头 | 沿摄像头朝向的水平分量移动 |
| **A** | 向左移动摄像头 | 沿摄像头左侧方向移动 |
| **S** | 向后移动摄像头 | 沿摄像头朝向的反方向移动 |
| **D** | 向右移动摄像头 | 沿摄像头右侧方向移动 |
| **Space（空格）** | 摄像头上升 | 按住持续上升 |
| **Ctrl（左）** | 摄像头下降 | 按住持续下降 |
| **Escape（ESC）** | 暂停菜单 | 打开暂停菜单（继续/退出/重开/退出游戏） |

## UI 按钮操作

| 按钮 | 功能 | 说明 |
|------|------|------|
| **旋转** | 进入旋转模式 | 高亮半径=3格的点位，点击朝向目标（右侧面板） |
| **移动** | 进入移动模式 | 高亮移动范围内的点位，点击可移动（右侧面板） |
| **攻击** | 进入攻击模式 | 高亮攻击范围内的点位，点击发射投射物（右侧面板） |
| **技能A** | 占位 | 待实现（右侧面板） |
| **结束回合** | 结束当前回合 | 底部左侧按钮 |

## 主菜单按钮（右侧35%区域）

| 按钮 | 功能 |
|------|------|
| **开始对战** | 进入对战关卡（test-Map02） |
| **AI对战** | 进入AI对战模式（占位） |
| **卡组编辑** | 进入卡组编辑界面（占位） |
| **创建房间** | 进入创建房间页面（联机主机） |
| **加入房间** | 进入加入房间页面（输入IP连接） |
| **快捷键** | 查看快捷键说明 |
| **退出** | 退出游戏 |

## 暂停菜单按钮（ESC）

| 按钮 | 功能 |
|------|------|
| **继续游戏** | 关闭暂停菜单，继续对局 |
| **退出（判负）** | 判负并退回启动器 |
| **重开** | 重新开始当前对局 |
| **退出游戏** | 结束游戏进程 |

---

## 代码位置

快捷键绑定定义在：
- `Source/newProject/TacticalPlayerController.cpp` → `SetupInputComponent()` 函数

如需修改或添加快捷键，编辑该函数中的 `InputComponent->BindKey(...)` 调用。
