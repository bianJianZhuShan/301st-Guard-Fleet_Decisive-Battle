# 舰船数值配置

## 当前代码配置表（ShipDataConfig.h）

### 配置参数说明

| 参数 | 说明 | 单位 |
|------|------|------|
| MaxHealth | 最大生命值 | 点 |
| AttackDamage | 攻击伤害 | 点 |
| AttackRange | 攻击范围 | 格 |
| AttackAPCost | 攻击消耗AP | AP |
| MoveRange | 移动范围 | 格 |
| MoveAPCost | 移动消耗AP总量 | AP |
| MoveAPPerGrid | 每几格消耗1AP | 格/AP |
| PointCost | 卡组点数成本 | 点 |
| bIsFlagship | 是否为旗舰 | 是/否 |

### 修改方法

在 `Source/newProject/ShipDataConfig.h` 的 `InitializeConfigs()` 函数中修改：

```cpp
// 格式：FShipDataConfig(名称, 类型, 血量, 攻击, 攻击范围, 攻击AP, 移动范围, 移动AP, 每几格1AP, 点数, 是否旗舰)
ShipConfigs.Add(EUnitType::Frigate, FShipDataConfig(
    TEXT("护卫舰"), EUnitType::Frigate,
    80,   // 血量
    15,   // 攻击伤害
    3,    // 攻击范围
    2,    // 攻击AP消耗
    4,    // 移动范围
    2,    // 移动AP总量
    2,    // 每2格消耗1AP
    3     // 点数成本
));
```

## 在 UE 编辑器中创建 DataAsset

### 步骤

1. 打开 Unreal Editor
2. 在 Content Browser 中右键 → **Miscellaneous** → **Data Asset**
3. 选择 **UnitDataAsset** 类
4. 命名为 `DA_舰船名称`（如 `DA_Frigate`、`DA_Destroyer`）
5. 双击打开，填写上表中的数值

### 字段对应关系

| 表格字段 | DataAsset 字段 | 类型 |
|----------|----------------|------|
| 单位名称 | DisplayName | FText |
| 类型 | UnitType | EUnitType |
| 点数成本 | PointCost | int32 |
| 血量 | MaxHealth | int32 |
| 攻击距离 | AttackRange | int32 |
| 攻击伤害 | AttackDamage | int32 |
| 移动距离 | MoveRange | int32 |
| AP消耗 | AttackAPCost | int32 |
| 小型槽 | SmallSlots | int32 |
| 中型槽 | MediumSlots | int32 |
| 大型槽 | LargeSlots | int32 |
| 特殊槽 | SpecialSlots | int32 |

### 外观配置

| 等级 | 缩放比例 | 说明 |
|------|----------|------|
| T4 (重巡) | 1.0 | 基准 |
| T3 | 0.75 | 缩小25% |
| T2 | 0.5625 | 缩小25%×2 |
| T1 | 0.42 | 缩小25%×3 |
| T5 | 1.25 | 放大25% |
| T6 | 1.5625 | 放大25%×2 |

## 代码中使用 DataAsset

```cpp
// 在 GridSpaceActor.cpp 中使用
UUnitDataAsset* FrigateData = LoadObject<UUnitDataAsset>(nullptr, TEXT("/Game/Data/DA_Frigate"));
SpawnUnitFromDataAsset(FIntVector(2, 5, 2), FrigateData, false);
```

或在蓝图中直接引用 DataAsset 资产。
