# 联机说明

## 概述

本项目支持基于局域网（LAN）的 1v1 联机对战。使用 UE5 内置的 Listen Server 模式，一方作为主机，另一方作为客户端加入。

## 网络架构

- **主机（Host）**：创建房间的玩家，控制 **Player 坐席**（友方单位）
- **客户端（Client）**：加入房间的玩家，控制 **AI 坐席**（敌方单位）

## 使用 WireGuard 组建虚拟局域网

如果两台电脑不在同一物理局域网，可以使用 WireGuard 组建虚拟局域网：

1. 在服务器上安装并配置 WireGuard
2. 为每台客户端生成配置文件
3. 连接后，所有设备在同一虚拟网段（如 `10.0.0.x`）

## 操作步骤

### 主机（创建房间）

1. 启动游戏
2. 在主菜单点击 **"创建房间（联机主机）"**
3. 游戏将以 Listen Server 模式加载对战关卡
4. 等待客户端加入

### 客户端（加入房间）

1. 启动游戏
2. 在主菜单点击 **"加入房间（输入IP）"**
3. 游戏将连接到主机 IP（默认 `10.0.0.1:7777`）
4. 连接成功后自动加载对战关卡

> **注意**：当前版本 IP 地址硬编码在 `TacticalHUD.cpp` 中的 `JoinIPAddress` 变量。
> 如需修改，请编辑该变量或后续实现 IP 输入框。

## 默认端口

UE5 默认使用端口 **7777**。

确保防火墙允许该端口的 UDP 流量。

## 回合控制

- 联机模式下，回合系统正常运作
- 主机控制 Player 坐席（友方单位）
- 客户端控制 AI 坐席（敌方单位）
- 只有当前回合的玩家可以操作单位

## 技术实现

### 关键代码位置

| 文件 | 功能 |
|------|------|
| `TacticalPlayerController.h/cpp` | `HostGame()`、`JoinGame()`、`MySeat`、`IsMyTurn()` |
| `TacticalGameMode.cpp` | `PostLogin()` 分配玩家坐席 |
| `TacticalGameState.h/cpp` | `bIsMultiplayerMode`、`ConnectedPlayerCount`、网络复制 |
| `TacticalHUD.cpp` | 联机按钮 UI |

### 网络复制属性

以下属性会自动同步到所有客户端：

- `TacticalGameState::CurrentSeat`
- `TacticalGameState::TurnNumber`
- `TacticalGameState::bIsMultiplayerMode`
- `TacticalPlayerController::MySeat`

## 已知限制

1. **IP 地址硬编码**：当前版本需要手动修改代码中的 IP
2. **无房间列表**：需要手动输入 IP 地址
3. **无断线重连**：断开连接后需要重新开始
4. **无聊天功能**：玩家间无法通信
