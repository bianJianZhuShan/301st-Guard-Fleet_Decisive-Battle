## 1. 游戏概述

### 1.1 游戏简介

3D太空战术棋类游戏，融合象棋、军棋的策略性和太空战斗的科幻感。

- **战场空间**: 10×10×10的立方体空间（共1000个顶点位置）
- **移动机制**: 每个单位可在球形范围内移动到任意顶点
- **行动点系统**: 每回合10点行动点，用于移动和攻击
- **回合制**: 点数耗尽或主动结束回合后切换到下一玩家

### 1.2 游戏模式

| 模式 | 说明 |
|------|------|
| **1v1对战** | 标准对战模式 |
| **AI对战** | 单人对战AI |
| **联机对战** | 局域网1v1对战 |

### 1.3 胜利条件

- 消灭所有敌方单位
- 或击毁敌方旗舰

## 2. 操作说明

### 2.1 基本操作

| 操作 | 说明 |
|------|------|
| **选中单位** | 左键点击己方舰船 |
| **取消选择** | 右键点击任意位置 |
| **双击聚焦** | 双击己方单位，摄像头聚焦到该单位 |

### 2.2 移动操作

1. 左键选中己方单位
2. 点击底部操作栏的"移动"按钮进入移动模式
3. 移动范围内的顶点会高亮显示
4. 鼠标悬停显示移动预览（虚线框、路径线、距离/AP信息）
5. 点击高亮顶点执行移动

### 2.3 攻击操作

1. 左键选中己方单位
2. 点击底部操作栏的"攻击"按钮进入攻击模式
3. 攻击范围内的顶点显示红色高亮
4. 鼠标悬停显示攻击预览（路径线、伤害/AP信息）
5. 点击敌方舰船或范围内顶点发射投射物

### 2.4 旋转操作

1. 左键选中己方单位
2. 点击底部操作栏的"旋转"按钮进入旋转模式
3. 旋转模式下会高亮半径=3格内的点位
4. 点击高亮点位：单位朝向该点位（支持三维朝向）
5. 点击敌方单位：可直接朝向敌方单位（无需点位高亮）

### 2.5 回合操作

- 点击"结束回合"按钮结束当前回合
- 回合切换后，对方开始行动
- 每回合开始时恢复行动点

## 3. 快捷键

> **20.3 版本更新**：快捷键已重构为 WASD 移动摄像头

### 3.1 鼠标操作

| 按键 | 功能 | 说明 |
|------|------|------|
| **左键单击** | 选中/操作 | 点击友方单位选中；在移动/攻击/旋转模式下点击目标执行操作 |
| **左键双击** | 聚焦单位 | 双击友方单位，摄像头聚焦到该单位后方上方 |
| **右键单击** | 取消选择 | 取消当前选中的单位，退出移动/攻击/旋转模式 |
| **滚轮向上** | 摄像头拉近 | 缩小视野距离 |
| **滚轮向下** | 摄像头拉远 | 放大视野距离 |

### 3.2 键盘操作

| 按键 | 功能 | 说明 |
|------|------|------|
| **W** | 向前移动摄像头 | 沿摄像头朝向的水平分量移动 |
| **A** | 向左移动摄像头 | 沿摄像头左侧方向移动 |
| **S** | 向后移动摄像头 | 沿摄像头朝向的反方向移动 |
| **D** | 向右移动摄像头 | 沿摄像头右侧方向移动 |
| **Space（空格）** | 摄像头上升 | 按住持续上升 |
| **Ctrl（左）** | 摄像头下降 | 按住持续下降 |
| **Escape（ESC）** | 暂停菜单 | 打开暂停菜单（继续/退出/重开/退出游戏） |

### 3.3 UI 按钮操作

| 按钮 | 功能 | 说明 |
|------|------|------|
| **旋转** | 进入旋转模式 | 高亮半径=3格的点位，点击朝向目标（右侧面板） |
| **移动** | 进入移动模式 | 高亮移动范围内的点位，点击可移动（右侧面板） |
| **攻击** | 进入攻击模式 | 高亮攻击范围内的点位，点击发射投射物（右侧面板） |
| **技能A** | 占位 | 待实现（右侧面板） |
| **结束回合** | 结束当前回合 | 底部左侧按钮 |

## 4. 联机对战

### 4.1 概述

本项目支持基于局域网（LAN）的 1v1 联机对战。使用 UE5 内置的 Listen Server 模式，一方作为主机，另一方作为客户端加入。

### 4.2 网络架构

- **主机（Host）**：创建房间的玩家，控制 **蓝方单位**（Seat0）
- **客户端（Client）**：加入房间的玩家，控制 **红方单位**（Seat1）

### 4.3 操作步骤

#### 主机（创建房间）

1. 启动游戏
2. 在主菜单点击 **"创建房间（联机主机）"**
3. 游戏将以 Listen Server 模式加载
4. 等待客户端加入
5. 对方准备后，点击"开始游戏"

#### 客户端（加入房间）

1. 启动游戏
2. 在主菜单点击 **"加入房间（输入IP）"**
3. 输入主机IP地址（默认端口 7777）
4. 连接成功后进入房间页面
5. 点击"准备"按钮
6. 等待主机开始游戏

### 4.4 使用 WireGuard 组建虚拟局域网

如果两台电脑不在同一物理局域网，可以使用 WireGuard 组建虚拟局域网：

1. 在服务器上安装并配置 WireGuard
2. 为每台客户端生成配置文件
3. 连接后，所有设备在同一虚拟网段（如 `10.0.0.x`）

### 4.5 默认端口

UE5 默认使用端口 **7777**。确保防火墙允许该端口的 UDP 流量。

### 4.6 回合控制

- 联机模式下，回合系统正常运作
- 主机控制蓝方单位（Seat0）
- 客户端控制红方单位（Seat1）
- 只有当前回合的玩家可以操作单位

### 4.7 已知限制

1. **IP 地址需手动输入**：当前版本需要手动输入 IP
2. **无房间列表**：需要知道主机 IP 地址
3. **无断线重连**：断开连接后需要重新开始
4. **无聊天功能**：玩家间无法通信

## 5. 界面说明

### 5.1 主菜单按钮

| 按钮 | 功能 |
|------|------|
| **开始对战** | 进入对战关卡 |
| **AI对战** | 进入AI对战模式 |
| **卡组编辑** | 进入卡组编辑界面（占位） |
| **创建房间** | 进入创建房间页面（联机主机） |
| **加入房间** | 进入加入房间页面（输入IP连接） |
| **快捷键** | 查看快捷键说明 |
| **退出** | 退出游戏 |

### 5.2 暂停菜单（ESC）

| 按钮 | 功能 |
|------|------|
| **继续游戏** | 关闭暂停菜单，继续对局 |
| **退出（判负）** | 判负并退回启动器 |
| **重开** | 重新开始当前对局 |
| **退出游戏** | 结束游戏进程 |

### 5.3 战斗界面

- **顶部**：显示当前回合、行动点、座席信息
- **右下角**：选中单位信息面板（血量、攻击、移动范围等）
- **底部**：操作按钮（移动/攻击/旋转/结束回合）
